🚀 Spread & Rest Operators in JavaScript

Deep Dive with Examples

📌 What is ... ?

The three dots (...) in JavaScript are used for two different purposes:

  • Spread Operator → Expands elements
  • Rest Operator → Collects elements

🔹 Spread Operator

Spread is used to expand arrays or objects.

Example: Array Merge

const arr1 = [1, 2, 3];
const arr2 = [4, 5];

const result = [...arr1, ...arr2];
console.log(result); // [1,2,3,4,5]

Example: Copy Array

const original = [1, 2, 3];
const copy = [...original];

copy.push(4);

console.log(original); // [1,2,3]
console.log(copy);     // [1,2,3,4]

Example: Object Update

const user = { name: "Chandan", age: 25 };

const updated = { ...user, city: "Bangalore" };

console.log(updated);

🔹 Rest Operator

Rest is used to collect multiple values into one variable.

Example: Function Parameters

function sum(...numbers) {
    return numbers.reduce((a, b) => a + b, 0);
}

console.log(sum(10, 20, 30)); // 60

Example: Array Destructuring

const nums = [1,2,3,4];

const [first, ...rest] = nums;

console.log(first); // 1
console.log(rest);  // [2,3,4]

Example: Object Destructuring


const person = {
    name: "Chandan",
    age: 25,
    city: "Bangalore"
};

const { name, ...others } = person;

console.log(name);   // Chandan
console.log(others); // { age: 25, city: "Bangalore" }

⚡ Key Difference

Spread  → Expands values (outward)
Rest    → Collects values (inward)

🔥 Real-World Usage

Immutable Update

const state = { count: 1 };
const newState = { ...state, count: 2 };

Function Flexibility

function logAll(...args) {
    console.log(args);
}

logAll(1,2,3,4);
